# Page Pack Nettoyage — SACKO CONCEPT

Le site est publié dans /pack-nettoyage/ du dépôt principal. La compilation scripts/build.mjs copie ce dossier vers dist/pack-nettoyage/.

## Commande
Les boutons ouvrent WhatsApp vers le numéro SACKO CONCEPT +1 505 464 2331, déjà configuré sur le site principal, avec un message concernant le pack standard à 119 USD. Le visiteur décide d’envoyer le message. Les liens sont dans index.html et fonctionnent sans JavaScript. Une icône flottante donne le même accès direct. Aucun paiement ni message n’est exécuté automatiquement.

## Aperçus réels
Six feuilles de registre distinctes sont affichées. Leurs tableaux de bord restent accessibles avec « Voir aussi le tableau de bord ». Les quatre extraits Word et leurs filtres sont conservés. Toutes ces images proviennent des fichiers fournis, avec des données de démonstration.

## Validation
La compilation complète du site doit réussir avant publication. Le paiement et la remise des fichiers se finalisent selon les modalités convenues lors de l’échange avec SACKO CONCEPT. La personnalisation avancée reste sur devis complémentaire.
